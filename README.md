# Site Volume — громкость для каждого сайта (Firefox)

Отдельная громкость для каждого сайта: от 0 до 600 %, басы и высокие ±15 дБ.
Настройки хранятся по домену (`youtube.com`, `vk.com` …) и применяются во всех вкладках
и iframe этого сайта. На иконке бейдж с процентом, если громкость не 100 %.

## Запуск

```bash
npx web-ext run            # Firefox с расширением, перезагрузка при правках
npx web-ext lint           # проверка (сейчас 0 ошибок, 0 предупреждений)
npx web-ext build          # zip для AMO
```

Без web-ext: `about:debugging` → «Этот Firefox» → «Загрузить временное дополнение» → `manifest.json`.
Вкладки, открытые до установки, нужно обновить.

## Как устроено

| Файл | Что делает |
|---|---|
| `content.js` | Ловит `<audio>/<video>` (событие `play` + обход DOM) и ведёт звук через Web Audio: lowshelf 200 Гц → highshelf 3.5 кГц → gain → лимитер → выход |
| `background.js` | Отдаёт контент-скрипту домен вкладки (чтобы iframe брали настройки сайта), рисует бейдж |
| `popup.*` | Интерфейс: дуга, ползунок, пресеты, эквалайзер, список сайтов |
| `shared.js` | `hostFromUrl`, значения по умолчанию |

Хранилище: `storage.local` → `{ sites: { "youtube.com": { volume: 2.5, bass: 5, treble: -3 } } }`.
Попап пишет туда, контент-скрипты слушают `storage.onChanged` — отдельные сообщения не нужны.

### Важные детали

- **Пока сайт на настройках по умолчанию, страница не трогается.** `createMediaElementSource` нельзя
  отменить, поэтому подключаемся только когда пользователь что-то поменял.
- **Чужие медиа без CORS.** Web Audio отдаёт их как тишину, поэтому такие элементы регулируются через
  `element.volume` — только тише, без усиления и эквалайзера. YouTube, Twitch, VK и большинство плееров
  используют MSE (`blob:`), с ними всё работает полностью.
- **Автоплей.** Если `AudioContext` не стартует без действия пользователя, расширение ждёт первого
  клика/клавиши на странице, иначе звук бы пропал.
- **Лимитер** включается только при усилении выше 100 %, чтобы не было хрипа.
- В Firefox нет `tabCapture` (так делают chrome-версии), поэтому подход через контент-скрипт.

## Ограничения / что можно добавить

- Не видит `new Audio()` вне DOM и медиа внутри closed Shadow DOM — для этого нужно патчить
  `HTMLMediaElement.prototype.play` в мире страницы (`wrappedJSObject` / `exportFunction`).
- Режим «по вкладке» в дополнение к «по сайту».
- Горячие клавиши (`commands`) для ±10 %.

## Публикация

`npx web-ext build` → загрузить zip на addons.mozilla.org (можно unlisted — тогда только подпись,
без каталога). ID в манифесте: `site-volume@shamsaev`, поменяй при желании до первой загрузки.
